# ST DevTools

ST DevTools는 SillyTavern용 읽기 전용 프롬프트 파이프라인 디버거입니다. 일반 채팅 프롬프트를 변경하지 않으면서 조립된 프롬프트와 생성 설정을 로컬에 캡처하고, 탐색기·타임라인·비교·컨텍스트·규칙 검사·검색 기능을 제공합니다.

## 현재 버전

`v0.3.0`

주요 기능:

- Magic Wand 메뉴에서 실행
- 밝은/어두운 테마를 감지하는 완전 불투명 패널
- 드래그·크기 조절이 가능한 한국어 UI
- 읽기 전용 상태 표시
- Chat Completion 및 Text Completion 요청 준비 시점 캡처
- 요청 모델·sampler·출력 설정과 민감 정보 제거 기록
- 캡처 경계와 사용한 SillyTavern 이벤트 표시
- 캐릭터 카드의 시스템 프롬프트·후처리 지시·예시 대화·첫 메시지·깊이 프롬프트 분리
- 소스가 최종 프롬프트에서 발견된 정확한 문자 범위 기록
- v0.1/v0.2 스냅샷을 스키마 v2로 자동 변환
- 활성화된 로어북 항목 캡처
- 채팅별 로컬 타임라인과 최근 100개 보관
- 소스별 색상·토큰 수·연결 신뢰도를 표시하는 프롬프트 탐색기
- 임의의 두 스냅샷 간 프롬프트 비교
- 컨텍스트 사용량과 캡처된 요청 본문 확인
- 일반 텍스트·대소문자·정규식 검색
- JSON·TXT·Markdown 내보내기
- 외부 API를 사용하지 않는 로컬 규칙 검사

## 캡처 정확성과 경계

가능한 경우 다음 요청 설정 이벤트를 우선 사용합니다.

- `CHAT_COMPLETION_SETTINGS_READY`
- `TEXT_COMPLETION_SETTINGS_READY`
- `GENERATE_AFTER_DATA`

이 이벤트에서 모델·sampler·프롬프트가 포함된 SillyTavern 프런트엔드의 백엔드 요청 데이터를 복제합니다. 같은 이벤트 전달 중의 동기적 설정 변경이 반영될 수 있도록 리스너 반환 직후 복제하며, 원본 객체는 수정하지 않습니다.

해당 이벤트를 제공하지 않는 구버전 또는 특수 생성 경로에서는 다음 prompt-ready 이벤트를 대체 경계로 사용합니다.

- `CHAT_COMPLETION_PROMPT_READY`
- `GENERATE_AFTER_COMBINE_PROMPTS`

각 스냅샷은 실제로 사용한 이벤트와 경계를 기록합니다. 캡처된 요청은 SillyTavern 프런트엔드가 자체 백엔드로 전달하는 데이터이며, 백엔드 또는 provider 내부에서 이루어지는 후처리까지 포함한다고 보장하지 않습니다.

API 키·인증 토큰·비밀번호·쿠키 등으로 판단되는 필드는 저장 전에 제거합니다.

## 규칙 검사

규칙 검사는 다음 항목을 로컬에서 확인합니다.

- 여러 소스에 중복된 문장
- 한 소스 안에서 반복되는 문장
- 한국어·영어·일본어·중국어 응답 지시 충돌
- JSON·XML·Markdown·일반 텍스트 출력 형식 충돌
- 여러 역할 선언
- 단일 소스의 과도한 토큰 점유
- 높은 컨텍스트 사용률
- 최종 프롬프트와 연결되지 않은 소스

정적 검사는 자연어의 의미 전체를 이해하지 못합니다. 결과는 검토 보조 자료이며 프롬프트 품질을 보증하지 않습니다.

## 설치

1. SillyTavern을 실행합니다.
2. **확장 → 확장 설치**를 엽니다.
3. 다음 저장소 주소를 입력합니다.

   ```text
   https://github.com/p16481012/SillyTavern-DevTools
   ```

4. SillyTavern을 새로고침합니다.
5. Magic Wand 메뉴에서 **ST DevTools**를 선택합니다.

SillyTavern `1.13.5` 이상이 필요합니다.

## 읽기 전용 원칙

ST DevTools는 `generate_interceptor`를 등록하지 않습니다. 이벤트 리스너는 캡처에 필요한 참조만 보관하고 즉시 반환하며, 토큰 계산과 IndexedDB 저장은 이후 실행됩니다. Playground가 추가되기 전까지 SillyTavern의 프롬프트·캐릭터 카드·설정을 변경하는 기능은 없습니다.

## 로컬 저장과 개인정보

스냅샷은 SillyTavern에 포함된 `localforage`와 IndexedDB를 사용해 채팅 ID별로 저장됩니다. 캐릭터 카드나 채팅 파일에는 추가되지 않습니다.

내보낸 파일에는 대화, 캐릭터 설정, 시스템 프롬프트 등 민감한 정보가 포함될 수 있으므로 공유하기 전에 반드시 내용을 검토하세요.

## 소스 연결 상태

- `정확`: 최종 프롬프트에서 원본 문자열과 해당 문자 범위를 확인
- `파생`: 캡처된 payload에서 재구성된 소스
- `미확인`: 매크로·템플릿·정규식 변환 또는 비활성화 때문에 동일 문자열을 확인하지 못한 소스

`미확인`은 해당 소스가 실제로 전송됐다는 뜻이 아닙니다.

## 개발

Node.js 20 이상이 필요합니다.

```bash

npm test
```

프로덕션 의존성과 빌드 단계는 없습니다.
