## 부분 구현 또는 알려진 경계

### Rule Inspector

- v0.8의 충돌 판정은 여전히 정규식과 정확 문장 비교입니다. 자연어 의미 전체를 이해하지 않습니다.
- 언어는 한국어·영어·일본어·중국어의 명시적인 응답 지시를 중심으로 검사합니다.
- 형식은 JSON·XML 및 Markdown·일반 텍스트처럼 명확한 비호환 쌍을 중심으로 검사합니다.
- 긍정·금지 지시는 설명·인용·이모지·코드 블록과 명시적인 이전 지시 무시 문구만 다룹니다.
- 역할 검사는 명시적인 선언을 찾지만 역할의 실제 범위, 조건과 우선순위 승자를 확정하지 않습니다.
- 이름 규칙은 프롬프트 이름만 해석합니다. 내용 의미를 이용해 그룹을 자동 추론하지 않습니다.
- `내부 무시`는 그룹 내부의 소스 쌍 비교와 그룹 경고만 숨깁니다. 컨텍스트·대형 소스 같은 단항 검사는 유지합니다.
- 그룹 밖 프롬프트는 의도적으로 계속 비교합니다.
- 비교 정책은 현재 브라우저 프로필 전체에 적용되며 아직 채팅·캐릭터·프리셋별 프로필은 없습니다.
- 비교 정책 내보내기·가져오기와 오탐 승인 기록은 아직 없습니다.
- 복잡한 매크로·조건부 조립·provider 변환은 설정 프롬프트의 실제 포함 상태를 확정하지 못할 수 있습니다.
- 과거 스냅샷에 안정적인 설정 identifier가 없으면 수동 지정이 이름 또는 소스 ID에 의존할 수 있습니다.

### 캡처·저장·추정

- 2026-07-29 기준 공식 SillyTavern prompt/settings 이벤트는 기본적으로 공개 요청 ID를 전달하지 않습니다. 공개 ID가 없는 일반 경로는 프롬프트 유형별 FIFO를 사용합니다.
- provider 서버가 변환한 실제 최종 HTTP 본문과 응답 패킷은 공개 프런트엔드 이벤트 범위 밖입니다.
- 저장 재시도는 일시적 IndexedDB 오류를 복구하지만 저장 할당량 부족·비공개 모드 제한 같은 근본 원인을 해결하지 않습니다.
- 진단 가져오기는 검토용 요약이며 스냅샷 백업·복원 또는 타임라인 병합 기능이 아닙니다.
- 멀티모달 추정은 캡처된 이미지 크기와 미디어 길이가 있을 때만 완전한 산정이 가능합니다.
- 실제 provider 응답 usage 또는 청구 토큰과 로컬 추정치는 다를 수 있습니다.
- 템플릿 provenance는 `{{...}}`, `${...}`, `<%...%>`, `<<...>>`만 지원하며 최대 20개 매크로·500자 치환 구간으로 제한합니다.
- 문장 재배열·조건부 블록·정규식 치환은 여전히 `미확인`일 수 있습니다.
- 마지막 assistant 메시지는 prefill 후보로 보수적으로 추정하므로 일반 마지막 응답과 구분하지 못할 수 있습니다.
- 로어북 비교는 활성화·제거·유지를 다루며 동일 UID 내부 내용 변경은 별도 상태로 표시하지 않습니다.
- 소스 diff는 내용·토큰·연결 상태를 비교합니다. role·depth·position·enabled만 바뀐 경우는 누락될 수 있습니다.
- 실제 IndexedDB와 SillyTavern/provider 통합 E2E는 사용자 환경 검토가 필요합니다.
