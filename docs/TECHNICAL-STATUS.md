## 부분 구현 또는 알려진 경계

- 2026-07-27 기준 공식 SillyTavern prompt/settings 이벤트는 기본적으로 공개 요청 ID를 전달하지 않습니다. 공개 ID가 없는 일반 경로는 프롬프트 유형별 FIFO를 사용합니다.
- provider 서버가 변환한 실제 최종 HTTP 본문과 응답 패킷은 공개 프런트엔드 이벤트 범위 밖입니다.
- 같은 요청 객체 또는 같은 공개 ID가 여러 호환 이벤트에 반복되면 중복으로 간주합니다. 호스트가 별도 생성에도 이를 재사용하면 request-ready 대신 prompt-ready 대체 캡처가 남을 수 있습니다.
- 정규화 provenance는 NFKC·대소문자·공백·zero-width 차이만 허용합니다. 변수 치환, 문장 재배열, 정규식 교체는 `미확인`일 수 있습니다.
- tool schema 토큰은 JSON 텍스트 토큰이며, 멀티모달 토큰은 placeholder 토큰입니다. provider가 청구하거나 실제 컨텍스트에 사용하는 이미지·오디오 토큰을 의미하지 않습니다.
- 마지막 assistant 메시지는 prefill 후보로 보수적으로 추정하므로 일반 마지막 응답과 구분하지 못할 수 있습니다.
- 로어북 비교는 활성화·제거·유지를 다루며 동일 UID 내부 내용 변경은 별도 상태로 표시하지 않습니다.
- 소스 diff는 내용·토큰·연결 상태를 비교합니다. role·depth·position·enabled만 바뀐 경우는 누락될 수 있습니다.
- 규칙 검사는 정규식 기반입니다. 자연어 의미, 조건부 예외, 실제 우선순위 승자를 확정하지 않습니다.
- 진단 보고서는 현재 채팅 타임라인만 다루며 문제 분석용 메타데이터 내보내기입니다. 원본 스냅샷 백업·복원 기능이 아닙니다.
- 100개 타임라인 순수 함수와 저장 회귀는 자동화했지만 실제 IndexedDB와 SillyTavern 통합 E2E는 사용자 환경 검토가 필요합니다.
