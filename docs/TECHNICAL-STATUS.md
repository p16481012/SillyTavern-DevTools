## 부분 구현 또는 알려진 경계

- 2026-07-27 기준 공식 SillyTavern prompt/settings 이벤트는 기본적으로 공개 요청 ID를 전달하지 않습니다. 공개 ID가 없는 일반 경로는 프롬프트 유형별 FIFO를 사용합니다.
- provider 서버가 변환한 실제 최종 HTTP 본문과 응답 패킷은 공개 프런트엔드 이벤트 범위 밖입니다.
- 저장 재시도는 일시적 IndexedDB 오류를 복구하지만 브라우저 저장 할당량 부족·비공개 모드 제한 같은 근본 원인을 해결하지는 않습니다.
- 전체 채팅 보고서는 인덱스에 남아 있고 실제 타임라인이 비어 있는 과거 항목을 자동 제외합니다.
- 진단 가져오기는 최대 5MB, 10,000개 스냅샷, 1,000개 익명 채팅, 중첩 12단계로 제한합니다.
- 진단 가져오기는 검토용 요약만 표시합니다. 스냅샷 백업·복원 또는 타임라인 병합 기능이 아닙니다.
- 멀티모달 추정은 캡처된 이미지 크기와 미디어 길이가 있을 때만 완전한 산정이 가능합니다.
- OpenAI GPT-5.6 `low`·`high`, 지원 목록 밖 모델, provider가 자체 변경한 리사이즈는 확정 계산하지 않습니다.
- Anthropic 상한을 넘는 이미지는 정확한 리사이즈 결과 대신 문서화된 최대 토큰을 `최대`로 표시합니다.
- 실제 provider 응답의 usage 또는 청구 토큰과 로컬 추정치는 다를 수 있습니다.
- 템플릿 provenance는 `{{...}}`, `${...}`, `<%...%>`, `<<...>>`만 지원하며 최대 20개 매크로·500자 치환 구간으로 제한합니다.
- 문장 재배열·조건부 블록·정규식 치환은 여전히 `미확인`일 수 있습니다.
- 마지막 assistant 메시지는 prefill 후보로 보수적으로 추정하므로 일반 마지막 응답과 구분하지 못할 수 있습니다.
- 로어북 비교는 활성화·제거·유지를 다루며 동일 UID 내부 내용 변경은 별도 상태로 표시하지 않습니다.
- 소스 diff는 내용·토큰·연결 상태를 비교합니다. role·depth·position·enabled만 바뀐 경우는 누락될 수 있습니다.
- 규칙 검사는 정규식 기반이며 자연어 의미, 조건부 예외, 실제 우선순위 승자를 확정하지 않습니다.
- 실제 IndexedDB와 SillyTavern/provider 통합 E2E는 사용자 환경 검토가 필요합니다.
