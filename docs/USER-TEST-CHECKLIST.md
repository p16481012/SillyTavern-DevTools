# v0.9.1 사용자 실사용 체크리스트

v0.9.1은 Rule Inspector V3 위에 비교 정책 프로필·정책 파일·검사 결과 검토 흐름을 추가한 버전입니다. 자동 테스트와 로컬 브라우저 샌드박스 검토는 완료했지만 실제 SillyTavern 프리셋·캐릭터·채팅 식별 경계는 사용자 환경에서 확인해야 합니다.

실제 API 키나 토큰을 테스트 데이터로 입력하지 마세요. 문제 보고에는 원문 전체 대신 개인정보를 제거한 최소 재현 문구를 사용하세요.

v0.9.1 이전 스냅샷은 전역 정책 검토에는 사용할 수 있지만 프리셋·캐릭터·채팅 범위 정보가 충분하지 않습니다. 아래의 범위 격리 항목은 업데이트 뒤 새로 보낸 일반 채팅에서 생성된 스냅샷으로 확인하세요.

## 먼저 확인할 핵심 8개

- [ ] 확장 목록과 ST DevTools 제목에 `v0.9.1`이 표시된다.
- [ ] 기존 v0.9.0 비교 정책이 업데이트 뒤 사라지지 않고 전역 V2 프로필로 이전된다.
- [ ] `출력언어 | 한국어`·`일본어`·`영어` 이름 규칙을 적용하면 내부 언어 충돌은 사라지고, 세 옵션이 실제로 함께 켜졌을 때 그룹 경고 한 건만 표시된다.
- [ ] 정책을 저장하고 SillyTavern을 새로고침해도 프로필·그룹 동작·이름 규칙·수동 지정이 유지된다.
- [ ] 검사 결과를 `오탐`으로 저장하면 재접속 뒤에도 숨겨지고 `검토됨·숨김 결과`에서 복원할 수 있다.
- [ ] `이번만 숨김`은 현재 패널에서만 숨겨지고 새로고침하면 다시 나타난다.
- [ ] 프리셋 범위의 `항상 무시`가 다른 프리셋에는 적용되지 않는다.
- [ ] 정책 JSON을 잘못 가져와도 기존 저장 정책과 판정이 바뀌지 않는다.

## 정책 프로필과 상속

- [ ] 현재 스냅샷에서 전체·프리셋·캐릭터·채팅 범위 이름이 사람이 읽을 수 있게 표시된다.
- [ ] 적용 순서가 `채팅 → 캐릭터 → 프리셋 → 전체`로 표시된다.
- [ ] 프리셋 프로필의 규칙이 일치하면 전역 규칙보다 먼저 적용된다.
- [ ] 좁은 프로필에 일치 규칙이 없으면 더 넓은 프로필 규칙으로 fallback한다.
- [ ] 채팅 프로필의 변경이 다른 채팅이나 캐릭터에 섞이지 않는다.
- [ ] 같은 범위 프로필을 UI에서 실수로 중복 생성할 수 없다.
- [ ] 같은 범위 우선순위를 바꾸면 높은 숫자의 프로필이 먼저 적용된다.

## 그룹 동작·이름 규칙·수동 지정

- [ ] `그룹 동작`을 먼저 만들고 여러 이름 규칙에서 같은 동작을 선택할 수 있다.
- [ ] `{group} | {option}`을 입력하면 저장 전 현재 스냅샷의 일치 개수가 표시된다.
- [ ] 템플릿 규칙을 편집·삭제·위로·아래로 이동할 수 있고 첫 일치 규칙만 적용된다.
- [ ] 위험하거나 잘못된 정규식은 원문 전체를 노출하지 않는 짧은 오류로 거부된다.
- [ ] 수동 지정 목록에는 프롬프트 이름만 보이고 내부 식별자는 표시되지 않는다.
- [ ] 여러 프롬프트를 한 번에 선택해 수동 지정할 수 있다.
- [ ] 수동 지정은 이름 규칙보다 우선한다.
- [ ] identifier가 없는 과거 소스도 가능한 경우 보조 지문값으로 재적용되고, 모호한 중복 후보에는 오적용되지 않는다.

## 변경 미리보기와 저장

- [ ] 정책을 수정하면 `저장하지 않은 변경 있음`이 표시된다.
- [ ] `현재 스냅샷 미리보기`에 변경 전·후, 새로 나타남·사라짐·유지됨과 제외 비교 수가 표시된다.
- [ ] 규칙 활성화나 임계값을 함께 가져오면 미리보기의 변경 전·후 분석이 서로 다르게 계산된다.
- [ ] 소스별로 그룹·옵션, 적용 프로필과 수동 지정·이름 규칙 근거가 표시된다.
- [ ] 프롬프트가 많은 스냅샷에서도 배정 카드는 최대 100개만 표시되고 패널 조작은 계속 가능하다.
- [ ] `설정 적용` 성공 뒤 저장 상태가 표시되고 버튼이 즉시 다시 눌릴 수 있다.
- [ ] 복원 가능한 저장 실패를 재현하면 성공으로 표시되지 않고 기존 저장 설정이 복원된다.

## 검사 결과 검토

- [ ] `유효` 판정은 카드에 검토 상태로 표시되고 같은 결과의 더 넓은 항상 무시보다 우선한다.
- [ ] `오탐` 판정은 같은 의미 근거의 결과를 이후 분석에서 숨긴다.
- [ ] `항상 무시`의 기본 범위는 현재 적용 가능한 가장 좁은 프로필이며 사용자가 다른 적용 범위를 직접 선택할 수 있다.
- [ ] 프리셋·캐릭터·채팅별 항상 무시가 각 범위를 벗어나 적용되지 않는다.
- [ ] `이번만 숨김`은 새로고침 뒤 복원되고 영구 판정 수에는 들어가지 않는다.
- [ ] `검토됨·숨김 결과`에서 판정·무시를 복원할 수 있다.
- [ ] 정책 적용·판정·무시·복원이 `로컬 감사 기록`에 시간순으로 남는다.

## 정책 JSON

- [ ] 판정 미포함 내보내기에는 규칙 설정과 정책만 있고 프롬프트 원문·감사 기록은 없다.
- [ ] 판정 포함을 체크하면 유효·오탐·항상 무시가 포함된다.
- [ ] 내보낸 파일에 프로필·패턴·수동 지정 이름·식별값이 포함될 수 있다는 안내가 보인다.
- [ ] 정상 파일을 가져오면 즉시 영구 저장되지 않고 초안·변경 미리보기로 표시된다.
- [ ] 가져온 초안을 추가로 편집한 뒤 적용해도 가져온 규칙 설정이나 판정이 덮어써지지 않는다.
- [ ] 지원하지 않는 버전, 알 수 없는 필드, 끊어진 그룹 참조, 위험 정규식과 1 MiB 초과 파일은 거부된다.
- [ ] 판정이 없는 파일을 가져오면 기존 로컬 판정은 유지된다.

## UI·성능·기존 기능 회귀

- [ ] 약 420~430px 폭에서 정책 프로필·그룹·규칙·수동 지정 컨트롤이 패널 밖으로 넘치지 않는다.
- [ ] 긴 도움말이 모바일 viewport 밖으로 나가지 않고 내부에서 읽을 수 있다.
- [ ] 밝은·어두운·자동 테마에서 정책 상태·판정 배지와 오류 메시지가 읽기 쉽다.
- [ ] 정책 미리보기를 반복해서 접고 펼쳐도 눈에 띄는 장시간 멈춤이 없다.
- [ ] 톱니바퀴 설정을 적용한 뒤 버튼이 다시 활성화되고 테마를 재차 저장할 수 있다.
- [ ] 스냅샷 개별·다중 삭제, 성장 그래프, 탐색기, 비교, 컨텍스트와 검색이 정상 동작한다.
- [ ] 보관 수와 불러오기 수의 분리 및 기존 배열형 스냅샷 이전 동작이 유지된다.

## 문제 보고 시 기록

- [ ] SillyTavern 버전, 브라우저, API 유형, provider, 모델과 생성 유형을 기록한다.
- [ ] 선택한 정책 프로필 범위·우선순위·그룹 동작·이름 규칙 또는 수동 지정 여부를 기록한다.
- [ ] 기대 판정과 실제 판정, `유효`·`오탐`·`항상 무시` 상태를 기록한다.
- [ ] 가져오기 문제라면 화면의 짧은 오류 코드와 판정 포함 여부를 기록한다.
- [ ] 원문 전체 대신 오탐·누락을 재현하는 최소 문장과 개인정보를 제거한 진단 자료를 첨부한다.
