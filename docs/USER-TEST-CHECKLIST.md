# v0.6.0 사용자 실사용 체크리스트

v0.6.0은 자동 검사와 브라우저 샌드박스를 통과한 상태로 배포합니다. 아래 항목은 실제 SillyTavern·provider 조합에서만 확인할 수 있는 대규모 검토 항목입니다.

## 설치와 회귀

- [ ] 확장 목록과 ST DevTools 제목에 `v0.6.0`이 표시된다.
- [ ] 사용 중인 밝은/어두운 테마에서 패널 배경이 불투명하고 글자가 읽힌다.
- [ ] 일반 생성 결과나 캐릭터 카드가 ST DevTools를 열기 전후로 바뀌지 않는다.
- [ ] v0.5 이전에 저장한 타임라인이 사라지지 않고 스키마 v3로 열린다.

## 캡처와 요청 연결

- [ ] Chat Completion과 Text Completion 스냅샷의 컨텍스트 탭에 이벤트·캡처 경계·요청 연결 방식이 표시된다.
- [ ] 현재 공식 기본 경로에서는 대체로 `이벤트 도착 순서(FIFO)`가 표시된다.
- [ ] 공개 요청 ID를 제공하는 커스텀 확장 경로에서는 `공개 요청 식별자 일치`가 표시된다.
- [ ] 두 생성을 빠르게 연속 실행해도 프롬프트·모델·출력 예약량이 서로 바뀌어 저장되지 않는다.
- [ ] API 키·토큰·암호 계열 필드가 원문으로 표시되지 않는다.
- [ ] 이미지·오디오 data URL은 원문 base64 대신 생략 안내와 개수가 표시된다.

## tool/function·멀티모달

- [ ] tool/function을 지원하는 모델에서 도구 스키마·도구 호출·도구 결과 소스가 각각 표시된다.
- [ ] 컨텍스트 통계의 도구 스키마·호출·결과 개수가 실제 요청과 일치한다.
- [ ] 이미지 또는 오디오를 첨부하면 전용 멀티모달 소스와 placeholder가 표시된다.
- [ ] 멀티모달 토큰 숫자를 provider의 실제 과금 토큰으로 오해하지 않도록 placeholder 기반이라는 경계를 확인한다.
- [ ] tool call이 포함된 최종 프롬프트 표시에서 함수명과 arguments가 누락되지 않는다.

## provenance

- [ ] 동일 문자열은 `정확`, 대소문자·공백만 달라진 문자열은 `정규화 연결`로 표시된다.
- [ ] 정규화 연결 소스에서 최종 프롬프트 이동·상호 강조가 올바른 범위를 가리킨다.
- [ ] 실제 매크로 변수 치환이나 문장 재배열은 무리하게 연결되지 않고 `미확인`으로 남는다.

## 타임라인 진단 보고서

- [ ] 타임라인 탭의 `진단 JSON`과 `진단 Markdown`이 현재 채팅의 모든 스냅샷 행을 포함한다.
- [ ] 보고서의 스냅샷 수·토큰 최소/최대/평균·캡처 방식·구조화 입력 합계가 화면과 일치한다.
- [ ] 보고서에 실제 프롬프트 문장, 요청 본문, 공개 요청 ID 값이 포함되지 않는다.
- [ ] 진단 내보내기가 기존 스냅샷 JSON·TXT·Markdown 내보내기와 구분된다.

## 키보드 접근성

- [ ] 패널을 열면 활성 탭에 포커스가 이동하고 Tab·Shift+Tab이 모달 밖으로 빠져나가지 않는다.
- [ ] Escape로 닫으면 패널을 열었던 Magic Wand 항목으로 포커스가 돌아온다.
- [ ] 탭에서 좌우 화살표와 Home·End로 화면을 바꿀 수 있다.
- [ ] 타임라인 성장 그래프 점을 Tab으로 선택하고 좌우/Home·End로 이동할 수 있다.
- [ ] 그래프 점에서 Enter 또는 Space를 누르면 해당 스냅샷 탐색기가 열린다.

## 기존 v0.5 기능 회귀

- [ ] 원본 소스↔최종 프롬프트 이동, diff, 로어북 변화, 규칙 검사, 검색이 기존처럼 동작한다.
- [ ] 페이지 새로고침과 채팅 이동 뒤에도 채팅별 타임라인이 분리되어 복원된다.
- [ ] 개별 삭제와 전체 비우기가 현재 채팅에만 적용된다.
- [ ] 스냅샷 JSON·TXT·Markdown 내보내기와 프롬프트 복사가 정상 동작한다.

## 결과 기록

- [ ] 문제가 있으면 SillyTavern 버전, API 유형, provider, 생성 유형, 모델, 캡처 이벤트·연결 방식, 재현 순서를 함께 기록한다.
- [ ] 공유하는 스냅샷에는 대화·캐릭터 설정이 포함될 수 있지만, 진단 보고서는 프롬프트 내용이 제외된다는 차이를 확인한다.
