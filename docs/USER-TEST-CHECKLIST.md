# v0.8.7 사용자 실사용 체크리스트

v0.8.7은 저장소·정규식·개인정보·캡처 lifecycle을 보강하는 안정성 패치입니다. 자동 테스트는 저장 인덱스 누락, 전체 삭제, 검색 취소·시간 제한, 생성 중단·종료, 캡처 전체 민감 정보 정제와 fuzz 입력을 포함합니다. 사용자는 아래의 실제 SillyTavern 통합 항목만 짧게 확인하면 됩니다.

실제 API 키나 토큰을 테스트 데이터로 입력하지 마세요. 민감 정보 검토가 필요하면 반드시 폐기 가능한 가짜 문자열을 사용하세요.

## 권장 5분 검토

- [ ] 확장 목록과 ST DevTools 제목에 `v0.8.7`이 표시된다.
- [ ] 타임라인의 `저장 상태`에 `IndexedDB · 영구 저장`, 전체 채팅 수, 스냅샷 수와 대략적 용량이 표시된다.
- [ ] 일반 생성을 한 번 완료하면 컨텍스트의 `캡처 시점·경계`에 요청 본문 캡처 상태와 `생성 종료됨`이 표시된다.
- [ ] 생성을 도중에 중단하면 같은 스냅샷이 하나 더 생기지 않고 기존 스냅샷의 상태가 `사용자가 생성 중단`으로 바뀐다.
- [ ] 검색어를 빠르게 입력해도 마지막 입력 결과만 나타나며 패널 조작이 멈추지 않는다.
- [ ] 정규식 검색에서 `(?<word>프롬프트)` 같은 안전한 패턴은 동작하고 `(a+)+$`는 위험한 패턴 안내와 함께 실행되지 않는다.
- [ ] 컨텍스트의 `복사·내보내기`를 펼치면 형식별 포함 내용과 원문 경고가 먼저 보인다.
- [ ] 복사 또는 내보내기 버튼을 누르면 확인 창이 나타나고 취소했을 때 클립보드·다운로드가 실행되지 않는다.

## 선택 검토

- [ ] 개발자 도구나 브라우저 설정 때문에 IndexedDB를 사용할 수 없는 환경에서는 `임시 메모리`와 새로고침 시 소실 경고가 표시된다.
- [ ] `sk-proj-` 뒤에 영숫자 32자를 붙인 가짜 값을 테스트 프롬프트에 넣어 새 스냅샷을 만든 뒤 JSON을 내보내면 원문 대신 `[민감 정보 제거됨]`이 표시된다.
- [ ] 가짜 URL query, Authorization 값과 PEM 개인 키도 같은 방식으로 제거된다.
- [ ] 이전 버전에서 만든 스냅샷을 열어도 내용과 ID가 유지되고 캡처 lifecycle은 `미확인`으로 안전하게 표시된다.

## 전체 삭제 검토

이 항목은 ST DevTools가 저장한 모든 채팅의 스냅샷과 규칙 설정·비교 정책·창 설정을 지웁니다. SillyTavern 채팅과 캐릭터 카드는 지우지 않지만 삭제한 ST DevTools 데이터는 복구할 수 없습니다.

- [ ] 타임라인의 `진단·관리 도구`에서 모든 데이터 삭제 항목과 영향을 설명하는 도움말을 확인한다.
- [ ] 확인 창에 전체 스냅샷 수가 표시되고 취소하면 아무 항목도 사라지지 않는다.
- [ ] 삭제를 승인하면 현재 채팅뿐 아니라 저장 상태의 전체 채팅·스냅샷 수와 용량이 0으로 바뀐다.
- [ ] 규칙 검사 설정과 비교 정책도 기본값으로 돌아가고, 다른 확장이나 SillyTavern 설정은 유지된다.
- [ ] 삭제 뒤 새 메시지를 보내면 새 스냅샷이 정상적으로 다시 저장된다.

## 중요 기능 회귀

- [ ] `출력언어 | 한국어`, `출력언어 | 일본어`, `출력언어 | 영어`와 `{group} | {option}` 비교 정책이 이전처럼 같은 대안 그룹으로 인식된다.
- [ ] 같은 그룹 내부 비교는 제외되지만 그룹 밖 언어 지시와의 비교는 유지된다.
- [ ] 비활성 또는 실제 요청 미포함 프롬프트가 비교·가장 큰 포함 소스·규칙 충돌에 다시 들어오지 않는다.
- [ ] 스냅샷 다중 선택·삭제, 성장 그래프, 소스별 diff와 원본↔최종 위치 이동이 동작한다.
- [ ] 밝은/어두운 테마와 약 420px 모바일 폭에서 저장 상태·캡처 상태·내보내기 안내가 가로로 잘리지 않는다.
- [ ] Tab·Shift+Tab 포커스 트랩, Escape 닫기와 탭 화살표/Home/End 이동이 동작한다.

## 문제 보고 시 기록

- [ ] SillyTavern 버전, 브라우저, API 유형, provider, 모델과 생성 유형을 기록한다.
- [ ] 저장 상태에 표시된 backend와 문제가 난 캡처의 요청·생성 상태를 기록한다.
- [ ] 검색 문제는 정규식 여부와 실제 패턴을 기록하되 민감한 원문은 제거한다.
- [ ] 가능하면 원문 스냅샷 대신 개인정보가 제외된 진단 JSON을 첨부한다.
