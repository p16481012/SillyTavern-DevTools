# v0.5.0 사용자 실사용 체크리스트

## 설치와 기본 표시

- [ ] 확장 목록과 ST DevTools 제목에 `v0.5.0`이 표시된다.
- [ ] 사용 중인 밝은/어두운 테마에서 패널 배경이 불투명하고 글자가 읽힌다.
- [ ] 일반 생성 결과나 캐릭터 카드가 ST DevTools를 열기 전후로 바뀌지 않는다.

## 캡처

- [ ] Chat Completion으로 생성한 스냅샷의 컨텍스트 탭에 이벤트와 캡처 경계가 표시된다.
- [ ] Text Completion을 사용한다면 같은 항목을 한 번 더 확인한다.
- [ ] 모델, 출력 예약량과 주요 sampler 값이 실제 생성 설정과 일치한다.
- [ ] 요청 본문의 API 키·토큰·암호 계열 필드가 원문으로 표시되지 않는다.
- [ ] 일반 생성, 재생성, 스와이프, 이어쓰기의 생성 유형이 기대와 일치한다.
- [ ] 두 생성을 빠르게 연속 실행해도 각 요청의 프롬프트·모델·출력 예약량이 서로 바뀌어 저장되지 않는다.
- [ ] Text Completion을 빠르게 2회 실행해도 settings-ready와 generation-data 중복 이벤트가 다음 스냅샷을 누락시키지 않는다.

## 소스·타임라인·비교

- [ ] 소스 카드의 이동 버튼이 최종 프롬프트의 해당 문자열을 강조한다.
- [ ] 최종 프롬프트 문자열을 누르면 원본 소스 카드가 열린다.
- [ ] 연속 생성 3회 이상에서 토큰 증감과 성장 그래프가 시간순으로 표시된다.
- [ ] 로어북 항목을 켜고 끈 뒤 활성화·제거 목록이 맞는지 확인한다.
- [ ] 두 스냅샷의 전체·소스별·로어북 diff가 실제 변경과 일치한다.
- [ ] 스냅샷 하나를 삭제해도 나머지 타임라인과 그래프가 유지된다.
- [ ] 페이지를 새로고침해도 현재 채팅의 스냅샷이 IndexedDB에서 다시 표시된다.
- [ ] 다른 채팅으로 이동하면 타임라인이 분리되고, 원래 채팅으로 돌아오면 기존 기록이 복원된다.
- [ ] 테스트 채팅에서 100개를 초과해 저장하면 최신 100개만 남고 가장 오래된 항목이 제거된다.
- [ ] 타임라인 전체 비우기에서 취소하면 기록이 유지되고, 확인하면 현재 채팅만 비워지며 다른 채팅 기록은 유지된다.

## v0.5 규칙 검사

- [ ] 시스템·캐릭터·확장 프롬프트에 서로 다른 언어 또는 출력 형식 지시를 두면 규칙 카드가 생성된다.
- [ ] `관련 소스 보기`가 탐색기로 이동하고 관련 카드 모두를 강조한다.
- [ ] `최종 프롬프트 근거 보기`가 충돌 문구만 정확히 강조한다.
- [ ] “설명을 포함”과 “설명을 포함하지 않음”을 함께 두면 긍정·금지 충돌이 표시된다.
- [ ] “앞선/이전 지시를 무시”하는 문구를 두면 우선순위 경고와 해당 근거가 표시된다.
- [ ] 검사 설정에서 규칙 하나를 끄고 적용하면 해당 결과만 사라진다.
- [ ] 컨텍스트 경고·치명 기준을 조정하면 판정이 바뀐다.
- [ ] 대형 소스 최소 토큰·비율과 중복 검사 최소 문장 길이를 조정하면 해당 결과만 달라진다.
- [ ] 기본값 복원 후 75% 경고, 90% 치명, 1,000토큰·40% 대형 소스 기준으로 돌아온다.
- [ ] 창을 닫았다 열거나 페이지를 새로고침해도 검사 설정이 유지된다.
- [ ] 모든 규칙을 끄면 “모든 규칙 검사가 비활성화”라고 표시된다.

## 검색·복사·내보내기

- [ ] 일반 검색, 대소문자 구분 검색, 정규식 검색의 결과 수와 소스 이동이 맞다.
- [ ] 잘못된 정규식을 입력해도 창이 멈추지 않고 한국어 오류가 표시된다.
- [ ] 컨텍스트 탭의 복사 결과가 현재 프롬프트와 일치한다.
- [ ] JSON·TXT·Markdown 파일이 각각 내려받아지고 민감 정보가 마스킹되어 있다.

## 결과 기록

- [ ] 문제가 있으면 API 유형, 생성 유형, 사용 모델, 캡처 이벤트와 재현 순서를 함께 기록한다.
- [ ] 공유할 스냅샷·스크린샷에 대화나 캐릭터의 민감한 정보가 없는지 확인한다.
