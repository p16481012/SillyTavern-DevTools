# v0.7.0 사용자 실사용 체크리스트

v0.7.0은 자동 검사와 로컬 브라우저 샌드박스를 통과한 상태로 배포합니다. 아래 항목은 실제 SillyTavern·브라우저 저장소·provider 조합에서 확인할 항목입니다.

## 우선 확인

- [ ] 확장 목록과 ST DevTools 제목에 `v0.7.0`이 표시된다.
- [ ] v0.6 이하에서 저장한 스냅샷이 사라지지 않고 스키마 v4로 열린다.
- [ ] 일반 메시지를 보낸 뒤 새 스냅샷이 한 번만 추가된다.
- [ ] 두 생성을 빠르게 연속 실행해도 두 스냅샷이 모두 남고 모델·프롬프트가 서로 바뀌지 않는다.
- [ ] 채팅을 바꾸면 각 채팅의 타임라인이 분리되어 표시된다.
- [ ] 개별 삭제와 전체 비우기 뒤 새 스냅샷을 저장해도 해당 채팅이 정상 복원된다.

## 저장 실패와 재시도

- [ ] IndexedDB 쓰기가 실제로 실패하는 환경에서는 패널 상단에 한국어 오류가 표시된다.
- [ ] 캡처 저장 오류의 `다시 시도`가 같은 스냅샷 ID를 저장하며 중복 항목을 만들지 않는다.
- [ ] 읽기·개별 삭제·전체 비우기 실패도 패널을 닫지 않고 오류와 재시도를 제공한다.
- [ ] 오류의 `닫기`는 안내만 숨기고 기존 타임라인을 삭제하지 않는다.
- [ ] 저장 할당량 부족처럼 재시도로 해결되지 않는 오류는 계속 실패로 표시되고 기존 데이터는 유지된다.

## 전체 채팅 진단과 가져오기

- [ ] `진단 JSON`·`진단 Markdown`은 현재 채팅 스냅샷만 포함한다.
- [ ] `전체 진단 JSON`·`전체 진단 Markdown`은 저장된 여러 채팅을 `chat-1`, `chat-2`처럼 익명화한다.
- [ ] 전체 보고서에 실제 채팅 ID, 프롬프트 문장, 요청 본문, 공개 요청 ID 값이 없다.
- [ ] 보고서의 채팅·스냅샷 수, 토큰 범위, 캡처 방식, 멀티모달 추정 합계가 화면과 대체로 일치한다.
- [ ] 방금 내보낸 진단 JSON을 가져오면 범위·스냅샷·채팅 수와 “검토 전용” 안내가 표시된다.
- [ ] 가져온 진단은 현재 타임라인에 스냅샷을 추가하거나 기존 데이터를 덮어쓰지 않는다.
- [ ] JSON을 깨뜨리거나 `content`, `payload`, `chatId` 같은 원문 필드를 추가하면 가져오기가 거부된다.
- [ ] 5MB 초과 파일, 지원하지 않는 보고서 버전, 개수가 맞지 않는 보고서는 거부된다.

## 멀티모달 토큰 추정

- [ ] 이미지 입력 소스에 `약`·`최소`·`최대`·`추정 불가` 중 하나와 제공자·산정 방식이 표시된다.
- [ ] OpenAI 지원 모델에서 이미지 크기와 detail이 있으면 32px 패치 또는 512px 타일 방식이 표시된다.
- [ ] Anthropic 이미지에 크기가 있으면 28px 패치 방식, 큰 이미지에는 상한임을 뜻하는 `최대`가 표시된다.
- [ ] Gemini 이미지·오디오·비디오에 크기 또는 길이가 있으면 타일·초당 방식이 표시된다.
- [ ] 크기·길이를 SillyTavern 요청에서 제공하지 않는 경우 임의의 확정값 대신 하한 또는 `추정 불가`가 표시된다.
- [ ] 컨텍스트 탭의 멀티모달 추정 합계와 추정 가능 비율이 개별 소스와 일치한다.
- [ ] 이 숫자를 provider 응답의 실제 usage나 청구 금액으로 오해하지 않도록 추정 문구가 명확하다.

## 템플릿 provenance

- [ ] 동일 문자열은 `정확`, 대소문자·공백 차이는 `정규화 연결`로 유지된다.
- [ ] `{{name}}`, `${name}`, `<%name%>`, `<<name>>`가 실제 값으로 치환된 단순 템플릿은 `템플릿 후보`와 신뢰도를 표시한다.
- [ ] 템플릿 후보에서 최종 프롬프트 이동과 강조 범위가 고정 문자열 앞뒤를 포함한 실제 치환 구간을 가리킨다.
- [ ] 고정 문자열이 짧거나 매크로가 과도한 템플릿은 무리하게 연결되지 않고 `미확인`으로 남는다.
- [ ] 문장 재배열이나 조건부 템플릿을 확정 연결로 오해하지 않는다.

## 기존 기능 회귀

- [ ] 밝은/어두운 테마에서 패널 배경이 불투명하고 새 오류·진단 카드의 글자가 읽힌다.
- [ ] 원본 소스↔최종 프롬프트 이동, diff, 로어북 변화, 규칙 검사, 검색이 기존처럼 동작한다.
- [ ] tool schema·호출·결과 소스와 구조화 입력 개수가 실제 요청과 일치한다.
- [ ] API 키·토큰·암호 계열 필드와 미디어 data URL 원문이 저장되지 않는다.
- [ ] 스냅샷 JSON·TXT·Markdown 내보내기와 프롬프트 복사가 정상 동작한다.
- [ ] Tab·Shift+Tab 포커스 트랩, Escape 닫기, 탭 화살표/Home/End, 성장 그래프 키보드 탐색이 동작한다.
- [ ] ST DevTools를 열거나 진단을 가져와도 SillyTavern 프롬프트·캐릭터 카드·생성 설정이 바뀌지 않는다.

## 문제 보고 시 기록

- [ ] SillyTavern 버전, 브라우저, API 유형, provider, 모델, 생성 유형을 기록한다.
- [ ] 캡처 이벤트·경계·요청 연결 방식, 멀티모달 산정 방식, 재현 순서를 함께 기록한다.
- [ ] 가능하면 원문 스냅샷 대신 개인정보가 제외된 진단 JSON을 첨부한다.
